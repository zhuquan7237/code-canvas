# Coral Paintbrush · layer source

Vector adaptation of this repository's Android Coral Paintbrush artwork, not an Apple asset. Import the three transparent 1024 × 1024 SVGs into [Icon Composer](https://developer.apple.com/icon-composer/) in numeric back-to-front order without changing their alignment. Use a soft warm background (for an initial light study, #FFE1CB to #FFAC94); review tinted, clear, dark and light appearances. The thin light outline around the pen is a silhouette separator, not baked illumination. Let Icon Composer supply the shape, lighting, refraction and shadow. Do not hide the dark nib or place uncontrolled shadows behind the code marks. Test at Home Screen, Spotlight and small Settings sizes.

These files are layer art, not a compiled or verified .icon file. Use [Apple’s icon guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons/) before integrating a final icon.
