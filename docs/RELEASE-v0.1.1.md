# 代码画布 v0.1.1

把 AI 给出的代码，变成看得见的作品。

## 下载与体积

- `code-canvas-0.1.1.apk`：57513 字节，约 56.2 KiB。
- Android 8.0+，使用系统 WebView，不打包浏览器内核，无广告、无需账号。
- 沿用旧版签名，可覆盖 v0.1.0 保留作品。

## 本版改进

- 首页「粘贴并预览」，点作品先看效果；不再用源码片段充满主页。
- 修复命名弹窗黑底黑字，适配日夜主题和可读状态栏。
- AI 围栏提取、多段代码选择、保留原文；已有代码可追加或替换，替换可撤销。
- HTML/SVG 真正渲染、已看过作品的真实缩略图；预览刷新、外部资源与项目兼容提示。
- 自动保存、任意后缀、系统导入导出、分享、撤销/重做。
- 默认实际离线；「联网加载」需确认，仅当前页面生效。JavaScript 另行启用。

## 已验证

- 30 项单元测试、11 项全量设备仪器测试通过。
- 实际签名正式版安装、日夜截图、HTML/SVG/XML 预览、系统 SAF 导出读回通过。
- 测试日志与截图在仓库 `docs/evidence`；Windows UTP 超时后使用 adb 直接执行全量仪器测试，详见验收记录。
- 尚未在小米 Turbo 3 / HyperOS 实机验证；请反馈手势、输入法与动画体验。

## 边界

普通 XML 是结构展示/校验，不是 Android 布局或 XSLT 渲染。不会编译 Vue/React 或运行 Python/Node.js。推荐 AI 输出单个自包含 HTML，CSS/JS 内嵌、不依赖 CDN。
