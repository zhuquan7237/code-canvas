# Code Canvas 0.6.7 · 安卓工作台 + 网页版

## Android

- 作品库增加可直接触达的格式筛选，保留单手粘贴、系统分享和长按多选。
- 搜索无结果时可以一键恢复；系统返回先清掉搜索，不会直接退出。
- 列表、网格和筛选控件对齐，明暗色层次更清楚。双列卡片的标题和元信息保留两行，长短文件名混排不会挤到下一行。高字号下切换为单列。
- 此次不更改 HTML/SVG 渲染、文件存储或签名方式。原有正式版可覆盖升级。

## Current web edition

- [在线打开](https://canvas.zhuquan.xyz/app/) / [English](https://canvas.zhuquan.xyz/app/?lang=en): paste, import, edit, preview and export local files. The app shell can reopen offline after it has cached successfully.
- Browser HTML and SVG preview is isolated, without scripts or external network resources. Other text is readable as source. Browser drafts do not sync; export before clearing site data.
- This Android release originally shipped the first web edition. The current site now uses the Apple design; use the links above instead of the archived first web build. The web app is not a native iOS app or an IPA.
