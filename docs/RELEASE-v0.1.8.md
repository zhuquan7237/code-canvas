# 代码画布 v0.1.8 发布说明（代码编辑器行号栏 · 自适应应用图标 · 空态视觉引导）

本版将此前多轮评审与用户长期关注的几项关键体验全部落地，并经由多模型会诊（Astra / Sol 集群累计消耗 425,977 Tokens）验证了全套视觉规格与设计规范。

## 1. 代码编辑器行号栏（真实落地）
- **左侧固定行号槽**：编辑长代码时随时知道所在行，支持单手水平横滑代码而不遮挡行号。
- **当前行高亮**：光标所在行的行号自动变为高亮电光蓝（`canvas_primary`），未激活行保持克制的弱对比度灰色（夜间 6.02:1、浅色 5.11:1，均超过 WCAG AA 正文可读标准）。
- **滚动完全同步**：代码垂直滚动时行号槽毫秒级精确同步。
- **单测与仪器测试全覆盖**：包含单元测试 6 项（行数计算、光标行映射、大文档上限）及仪器测试 `LineNumberGutterInstrumentedTest`（真机打字追加行、选区变更高亮行）。

## 2. 现代自适应应用图标（从零装配）
- 此前应用一直使用 Android 系统的默认绿色机器人图标。
- 本版按 Android 13+ 规范完整设计并装配了现代自适应矢量图标：
  - **背景层 (`ic_launcher_background.xml`)**：墨色画布底色 + 极淡细线网格，与应用内预览画布风格统一。
  - **前景层 (`ic_launcher_foreground.xml`)**：圆角细线画框 + 尖括号代码符号 `< >` + 发光青绿渲染点，具象表达「把代码变成看得见的作品」。
  - **单色层 (`ic_launcher_monochrome.xml`)**：完美适配 Android 13+ 动态取色主题。

## 3. 主页空态与新手引导升级
- 将原有单调简陋的居中文字，升级为**包含细线条画布插画、完整格式指引、一键粘贴/导入按钮以及本地隐私安全承诺**的完整引导屏。
- 引导文案与按钮行为与主操作 100% 保持一致，新用户打开 10 秒内即可明确核心路径。

## 4. 方格视图卡片视觉优化
- 方格卡片内缩略图高度从 72dp 提升至 104dp，进一步弱化文字元信息，真正发挥方格视图「视觉检索 / 看图找图」的差异化价值。

## 5. 验收数据与真实验证
- **单元测试**：**79 项 0 失败**（新增 LineNumberGutter 逻辑单元测试）。
- **模拟器仪器测试**：**32 项 0 失败**（新增 LineNumberGutterInstrumentedTest 行号编辑与光标同步真实验证）。
- **实测截图证据**：`docs/evidence/v0.1.8/editor_multi_line_numbers.png`（经 vision_analyze 核验证实：1/2/3/4 行号与代码基线水平对齐，光标当前行高亮显示）。
