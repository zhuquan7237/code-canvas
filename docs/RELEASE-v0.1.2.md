# 代码画布 v0.1.2

把 AI 给出的代码，变成看得见的作品。

## 下载与体积

- `code-canvas-0.1.2.apk`：**70787 字节（约 69.1 KiB）**，Android 8.0+，使用系统 WebView，不打包浏览器内核，无广告、无需账号。
- 沿用旧版签名（证书 SHA-256 `a6f25e1a490efbf985d753d216ffdbaeea360a9ab4b57ad2c156eabf553d19b6`，与 v0.1.0 / v0.1.1 相同），可覆盖安装并保留已有作品。
- **v0.1.1 没有更新器，升级到 0.1.2 需要手动装一次**；装好之后 0.1.3 起才能在应用内更新。

## 本版改进

### 1. 颜色对比度与区分度（本版最重要）

深浅色各自一套完整调色板，正文、次要文字、按钮、标签、语法高亮、状态色全部按 WCAG 2.1 AA 实测：

- 正文文字 ≥ 4.5:1；功能图标、描边、选中态指示 ≥ 3:1（对真实相邻底色测量）。
- 修复了旧版本里几个真实的「看不清」：

  | 位置 | 旧值 | 现在 |
  |---|---|---|
  | 禁用态主按钮（白字压 #9AA8BC 浅灰） | 2.41:1 | 改浅灰底 + 深灰字，5.07:1（夜间 7.50:1） |
  | 搜索框 / 分段选中态描边（浅色） | 2.25:1 | 4.14:1（夜间 3.57:1） |
  | 夜间 `border_strong` 压在深色面 | 2.67:1 | 3.07:1 |

- 图标按语义区分颜色：新增/刷新用蓝、更新用绿、联网告警用琥珀、编辑删除等中性操作走中性墨色，且夜间不再残留浅色主题的深色描边。

### 2. 主页紧凑列表与两列方格

- 默认紧凑列表，一行约 76dp，360×800dp 视口一屏可见 6 个以上完整文件；可切换两列方格（≈150dp 卡片），选择会跨重启保留。
- 卡片改为「缩略图 + 文件名 + 类型标签 + 大小/行数 + 时间 + ⋮ 菜单」，分享/删除收进「⋮」，不再占一整行。
- **修复了方格模式的崩溃**：方格卡片布局缺少 `txt_doc_time`，`getView` 无条件写它，进入方格就 NPE 崩溃；已补齐该控件并对全部卡片字段做了空值保护。

### 3. 代码 / 预览切换不再白屏闪烁

- 内容、标题、主题、JS/联网状态都没变时不重新加载 WebView（不再每次进预览都重载）；「刷新」按钮则强制重载。
- 渲染完成后才撤掉主题化加载遮罩，旧画面不会被清空成白屏；过期回调按代次丢弃。
- 切换用 160ms 位移过渡，并遵守系统「关闭动画」；渲染 15 秒未完成会明确提示而不是一直遮着。

### 4. 编辑器工具栏

- 撤销 / 重做 / 直接粘贴。
- 可横向滑动的常用符号条：Tab（插入 4 空格）、`<`、`>`、`/`、`=`、`"`、`{}`、`()`、`[]`；配对符号插入后光标停在中间，替换选区时遵守撤销历史与 2MB 上限。
- 查找/替换：上一处、下一处、替换、全部替换（一次撤销可回退），按原文匹配不做正则。
- 更多：全选、复制全部代码、跳转到行。

### 5. 应用内检查更新

- 启动时静默检查，成功检查 6 小时内不重复；可在「检查更新」上长按关闭自动检查。
- 主页底部常驻入口，显示已装版本与检查结果（发现新版本会变成「新版本 x.y.z · 点击更新」）。
- 下载前弹说明让你确认；下载中显示进度、可取消；完成后校验字节数、SHA-256、包名、versionCode 与签名证书，全部一致才交给系统安装器。缺「安装未知应用」权限时引导到本应用设置页，返回后自动继续。
- 清单地址只允许 `raw.githubusercontent.com` 上本仓库的 `docs/update/latest.json`，下载只允许本仓库 Release / GitHub 资源主机，拒绝未知主机、重定向到别处、降级版本与错误哈希。

## 尚未验证 / 边界

- 最后一步「系统安装器真正写盘完成」在测试模拟器上被 **Google Play Protect** 拦下（判定 "Harmful app blocked"）。这是系统级安全门，应用不会去绕过它。自签名侧载包在带 Play Protect 的设备上首次安装会出现该提示；国内 ROM（HyperOS 多不带 Play Protect）通常不受影响，但仍需你实机确认一遍。
- **仍未在小米 Turbo 3 / HyperOS 真机验证**：输入法、手势导航、120Hz 动画、厂商后台限制下的更新安装都需要你实机试用。
- 模拟器不能代表真机帧率；本版只保证「不重载、不白屏、有过渡」，没有承诺具体帧率数字。
- 普通 XML 只做结构展示与校验，不是 Android 布局渲染或 XSLT。不会编译 Vue/React，也不运行 Python/Node.js。推荐让 AI 输出单个自包含 HTML（CSS/JS 内嵌、不依赖 CDN）。
