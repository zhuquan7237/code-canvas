# Code Canvas v0.7.0 (Android)

## 中文

- 在其他 Android 应用中选中文字，选择「用代码画布打开」后，先进入临时原文查看页。不会运行代码、访问网络或自动创建作品，直接关闭即可返回原应用。
- 需要保留时，点「保存到作品库」。编辑器以源码模式打开已保存的副本，原应用的文字不会改动。较长的选区先显示开头，保存仍保留全文；超过编辑长度上限时不会自动打开编辑器。
- 临时文本不会进入最近任务的截图。若系统回收了进程，请回到原应用重新打开选区。

## English

- Choose **Open in Code Canvas** from an Android text selection to inspect the source temporarily. It does not run code, access the network, or create a library item. Close it to return to the other app.
- Tap **Save to library** to keep a copy. The saved copy opens in source mode without changing the source app. Long selections show an excerpt but save in full. Selections above the editor length limit do not automatically open the editor.
- Temporary source is excluded from Overview snapshots. If Android kills the process, reopen the selection from the original app.
