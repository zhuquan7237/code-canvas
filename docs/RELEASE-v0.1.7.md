# 代码画布 v0.1.7 发布说明（宽幅 SVG 完整无裁切 · 横屏全屏欣赏模式）

本版专门针对用户反馈的宽幅 SVG 实际体验问题修复：导入宽幅矢量画作（如 1280×800 的《海滩骑行日记》）在竖屏手机上只能看到中间一条、左右两侧被裁掉 60% 的严重问题，以及缺少全屏大图模式的体验短板。

## 1. 为什么有的 SVG 导入预览只能看到中间一部分

**根因诊断：**
1. **作者代码含有 `preserveAspectRatio="...slice..."`**：`slice` 的 SVG 规范定义是“超出视口则裁切以填满整个容器”。在宽屏电脑上设计时作者希望填满，但在竖屏手机上，该属性会导致视口上下撑满、左右两侧整整 667 像素（超过 60% 的画面内容）被彻底裁掉！
2. **根标签内联样式包含 `width: 100vw; height: 100vh`**：强制拉大视口，导致缩放失衡。
3. **包装样式只声明了 `max-width` 缺少完整包含约束**。

**解决方案：**
- 在 `SvgWrapper.java` 中安全重写根 `<svg>` 标签属性：将任何 `slice` 智能替换为 `preserveAspectRatio="xMidYMid meet"`（完整适应，绝不裁剪！）；如果未声明，默认补齐 `meet`。
- 去除根 svg 上的内联 `100vw/100vh`，并在 CSS 容器中使用 `object-fit: contain !important; max-width: 100% !important; max-height: 100% !important;` 约束。
- **实测验证**：无论任何超宽、超长比例，画面整体自动等比 Letterbox 居中展示，四角边界（左、右、上、下）完整可见，0 像素裁切！

## 2. 宽幅作品支持全屏 / 横屏观看

**新增功能：**
- 在预览工具栏加入 **「全屏」** 按钮。
- 点击「全屏」即可**一键旋转为横屏沉浸式全屏**：隐藏顶部标题栏、操作栏与底部栏，充分利用手机宽屏尺寸放大呈现宏大宽幅矢量图和交互动画！
- 全屏状态下右上角提供半透明悬浮 **「退出全屏」** 按钮，点击或按下系统返回键即可无缝退出全屏、切回竖屏编辑模式。

## 3. 验收数据与真实验证

- **单元测试**：**73 项 0 失败**（新增 SvgWrapper 针对 slice/meet/vw/vh 属性清洗的完整单元测试）。
- **模拟器仪器测试**：**31 项 0 失败**（新增 `SvgPreviewFitsWholeArtworkTest` 针对用户代码与宽场景的 `getScreenCTM()` 真实屏幕坐标校验，新增 `PreviewFullscreenTest` 验证横竖屏全屏切换与退出）。
