# 代码画布 Android 0.6.5

versionCode 65 · minSdk 26

- SVG 按真实比例适配，首页缩略图从作品本身生成，不再被详情页的缩放或裁切覆盖。旧缩略图会重新生成。
- 独立 SVG 保留原生文档和脚本；HTML 保留网页和互动逻辑，单幅 SVG / Canvas 舞台按窗口适配。HTML 可双指或用按钮缩放；可在预览里控制页面脚本和联网。
- Mermaid 全图适配，可滚动、缩放。Android 9 及以上支持播放动态 WebP；PDF 过长页面限制渲染尺寸，快速翻页不会被上一页的异步结果覆盖。
- 预览适配不会修改原文件。HTML 里的外部资源仍需单页联网；与原文件同目录的资源不会在导入单文件时自动带入。
