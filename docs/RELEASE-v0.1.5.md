# 代码画布 v0.1.5 发布说明（评审第二轮补齐 + 手动下载兜底）

v0.1.4 已经把「应用内更新」和外部评审第一轮的问题修掉并发出去了。这一版是把**第二轮评审（交互 + 实际体验，完整版）**里还没处理的问题补上——第二轮第一次跑被上游截断了（只回来 1,085 字符），我重跑拿到完整的 11,342 字符后才发现这几条。

## 本版改了什么

| 改了什么 | 之前什么样 | 现在什么样 |
| --- | --- | --- |
| AI 回复里既有说明文字又有代码时的粘贴 | 没有代码围栏就直接把**整段回复**（含「这是你要的图表，具体尺寸可以调」这类说明）存成文档，用户没法纠正 | 认出「说明 + 代码」的情况后**让用户选**：只保存识别到的代码（推荐）/ 保存全文 / 取消；标题里说明按什么规则截的，选错可以直接重来 |
| 系统「打开方式」导入 | 只拿一次临时读取权限，导入在后台线程里跑，进程被重建后可能读不到而报错 | 额外申请**可持久化读取权限**（provider 不支持时静默退回一次性的），导入不再受重建影响 |
| 更新下载失败之后 | 只有「重试」和「关闭」——两个源都不通时用户只能一直点重试 | 多一个**手动下载**：直接用浏览器打开应用用的那个安装包地址，自己拿包 |

## 验收（数字都是实跑出来的）

- 单元测试 **62 项 0 失败**（新增 4 项：说明文字夹代码的截取规则，含「整段已经是标记语言时不许猜」「只有一行 `<br>` 不算代码」这类反例）
- 模拟器仪器测试 **26 项 0 失败**（无回归）
- 真机（模拟器）连续升级：已安装的 **0.1.4（versionCode 5）** 通过应用内更新装到 **0.1.5（versionCode 6）**，系统安装器自报 `App updated`，重开显示「已是最新 · 0.1.5」——这是**连续第二次**走通自建源通道，说明它不是一次性搭出来的

## 诚实边界

1. 「只保存识别到的代码」用的是**简单规则**（第一行尖括号到最后一行尖括号），不是 HTML 解析器；所以它把选择权交给用户，而不是自己拍板。规则判定「整段已经是代码」时不会多问。
2. 手动下载只是把地址交给浏览器，**下载和安装仍由系统和用户完成**，应用不参与，也不做校验——这条路径是逃生门，不是自动更新。
3. 评审第二轮里仍未处理的：编辑器关键操作的可发现性（长按 / 横向滚动 / 「更多」）、主页缩略图「打开过才有」这个语义本身、渲染类型识别的更激进判定。都记在 [docs/RELEASE-v0.1.4.md](RELEASE-v0.1.4.md) 的未做清单旁边，没有假装做完。
4. 老版本（≤0.1.4 之前的构建）里没有自建源，它们收不到这一版——这是通道本身的历史限制，不是本版能修的。
