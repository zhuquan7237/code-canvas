# v0.5.3 本次更新

第一阶段的文件预览与基础编辑、代码搜索、SVG 交互视口，以及更新链路的加固。

## 文件底层：先保存原始字节，再决定怎么读

以前每个导入的文件都被当成 UTF-8 文本：一张 PNG 会变成一堆乱码，一个 GB18030 的中文
文本会变成一片问号，而保存又会把乱码写回原文件。现在：

- 每个文件记录来源 URI、文件名、扩展名、MIME、大小、类型、编码、换行方式。
- 类型判断顺序是 **文件特征 → 扩展名 → MIME**。一个改名成 `.txt` 的 PDF 仍然是 PDF；
  真正的二进制文件会被明确拒绝并说明原因。
- 文本编码按 BOM → 严格 UTF-8 试解 → GB18030 的顺序识别，保存时用**同一个编码和同一种换行**写回。
- 图片和 PDF 的原始字节保存在应用内，未修改导出时**哈希不变**。

## 第一阶段格式

| 类型 | 预览 | 编辑 |
| --- | --- | --- |
| HTML / HTM | 网页渲染 | 源码编辑 |
| SVG | 矢量预览、自适应、缩放、拖动、全屏 | 源码编辑 |
| Markdown / MD | 表格、任务列表、代码块、公式、Mermaid | 原文编辑 |
| Mermaid / MMD | 图表渲染 | 源码编辑 |
| JSON | 结构化显示、格式化、行列错误提示 | 原文编辑 |
| JSONL | 逐行查看、错误行提示 | 原文编辑 |
| XML | 结构化文本、语法提示 | 原文编辑 |
| YAML / YML | 高亮、缩进与括号校验提示 | 原文编辑 |
| CSV | 表格预览、横向滚动 | 原始文本编辑 |
| TXT | 文本显示 | 文本编辑 |
| 常见代码 | 行号、语法高亮 | 基础代码编辑 |
| PNG / JPG / WebP | 图片预览、缩放、拖动 | 仅预览 |
| GIF | 动图播放 | 仅预览 |
| PDF | 原始文件保留、可交给系统阅读器 | 仅预览 |

代码覆盖 Python、JavaScript、TypeScript、Java、Kotlin、C/C++、CSS、SQL、Shell 等；
未知后缀按纯文本打开。

**离线可用**：Markdown、公式（KaTeX）和 Mermaid 的依赖随安装包提供，断网也能渲染。
HTML 里引用的远程字体、图片和脚本在离线时不会加载——这是两件不同的事，界面上也分开说明。

**格式化不篡改数据**：JSON 格式化只调整缩进，`1.0` 仍然是 `1.0`，
`12345678901234567890` 不会变成科学计数法，字符串里的转义原样保留。

## 代码搜索

- 搜索框、当前序号/总数、上一处、下一处、关闭、区分大小写。
- 普通文本匹配，支持中文、英文、符号和粘贴进来的多行代码。
- 全部匹配高亮，当前匹配用另一种颜色突出；切换时自动滚动到对应位置。
- 最后一处与第一处循环；无结果明确提示；编辑后计数自动更新。
- 有选中文字时自动填入搜索框。

## SVG 交互视口

- **默认完整显示**：首次打开按 viewBox（或宽高）计算适应比例并居中，四周留白。
  非零和负数原点（如 `viewBox="-200 -120 400 240"`）也正确居中。
- **双指缩放**围绕双指中心；**单指拖动**平移；**双击**以点击处放大、再双击复位；
  按钮放大/缩小围绕视口中心。
- 缩放范围 0.1～20 倍（相对适应比例），集中配置。
- 拖动有边界，不会把整张图移到完全看不见；**适应窗口**随时找回完整图形。
- **适应内容**临时扩大预览范围，用于查看被自身 viewBox 裁掉的图形；
  内部 `clipPath`/遮罩是有意裁切，语义原样保留。
- **全屏**：进入时完整显示，退出后恢复原状态，返回键先退出全屏。
- 横竖屏切换时，未手动缩放的会重新适应；已手动缩放的保留观察中心和放大程度。
- 缩放保持矢量渲染（不生成位图），手势期间只更新变换，不重新解析 SVG。
- **查看不会改动文件**：缩放、平移、全屏、适应内容都不会让文件变成"未保存修改"。

## 应用内更新

- 用递增的 versionCode 判断新旧，versionName 只用于显示。
- 清单新增 `minSdk` 与 `channel`：预发布版本一律拒绝安装；
  当前设备跑不动的版本会直接说明，不会先下载再失败。
- 安装前校验文件完整性、包名、版本、签名，以及安装包自身的 minSdk。
- 下载显示进度，支持取消和重试；未完成的文件不会进入安装。

## 这一版没做到的

- **PDF 不能在应用内翻页预览**。Android 的 WebView 不渲染 PDF，本阶段没有打包 PDF.js；
  界面明确说明，并提供"用其他应用打开原文件"和分享（字节一致）。
- **YAML 没有完整语义校验**。应用内没有 YAML 引擎，只检查缩进（含制表符）和括号平衡，
  界面明确标注"未做完整 YAML 语义校验"，不会假装通过。
- 搜索不支持正则、替换和跨文件。
- Office 文档、压缩包、音视频不在本阶段范围。
