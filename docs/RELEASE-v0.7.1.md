# Code Canvas v0.7.1 (Android)

## 中文

- 作品库用「数据与表格」「笔记本」「网页与图形」「阅读文档」「代码与文本」分类。CSV、TSV、JSON、JSONL、YAML 和 XML 放在同一组，不用再从「其他」找。
- 首页和目录使用同一套筛选。目录会直接显示仍在生效的搜索词和结果数；「清除筛选」一次清掉搜索与格式，不需要退出目录。
- 分类按作品实际支持的格式显示。旧版按纯文本保存的 .ipynb 仍可在「代码与文本」中找到。

## English

- Filter the library by Data & tables, Notebooks, Web & graphics, Documents, or Code & text. CSV, TSV, JSON, JSONL, YAML, and XML share the Data & tables group.
- Home and Catalog use the same filter. Catalog shows the active search and result count and can clear both search and format without leaving the panel.
- Categories use the document's actual supported format. Legacy .ipynb records saved as plain text remain under Code & text.
