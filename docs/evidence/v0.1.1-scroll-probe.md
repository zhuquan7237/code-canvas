# Scroll probe — not a smoothness pass

Tested the signed release home screen with two opposing 450ms swipes after `dumpsys gfxinfo com.nous.codecanvas reset`:

- Total frames: 35; janky frames: 30 (85.71%).
- p50: 48ms; p90: 93ms; p95: 129ms.

Control on the same emulator: system Pixel Launcher, two opposing 450ms swipes after its gfxinfo reset:

- Total frames: 27; janky frames: 25 (92.59%).
- p50: 121ms; p90/p95: 400ms.

Environment: Android 17 x86_64 emulator, 1080×2400, 2 CPU cores, 1536MB RAM, host GPU; another QA emulator is also running on the host. These are short, different-view workloads and NOT a controlled application-to-application benchmark. The launcher also misses deadlines badly, so this environment cannot establish a 60/120Hz smoothness acceptance result. It also does NOT establish that CodeCanvas will be smooth on real phones. Real Xiaomi Turbo 3 / HyperOS swipes, keyboard edits and transitions still need testing.

No layout or safety assertions were relaxed to obtain these numbers.
