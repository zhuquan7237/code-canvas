# 设计系统 · 留白（手机版）

代码画布在手机上是用来**看作品**的。界面让出空间，内容占住注意力。
这一版不再用一圈细描边把每张卡片框死，改用底色层次和固定的间距、圆角。

颜色的数值仍以 `res/values/colors.xml` 与 `values-night/colors.xml` 里的色板为准，
`ColorContrastTest` 继续要求正文 ≥ 4.5:1、功能色 ≥ 3:1。间距和圆角以 `res/values/dimens.xml` 为准。

## 间距

只用这一组，页面边距用 16，区块之间用 16 或 24，不要再写 10、14、20 这类中间值。

| token | 值 | 用途 |
| --- | --- | --- |
| `space_4` | 4dp | 图标和文字的细缝 |
| `space_8` | 8dp | 行内间隙 |
| `space_12` | 12dp | 紧凑的组内间距 |
| `space_16` | 16dp | 屏幕边距、卡片内边距、列表行距 |
| `space_24` | 24dp | 区块之间 |
| `space_32` | 32dp | 空状态的上留白 |

## 圆角

| token | 值 | 用在 |
| --- | --- | --- |
| `radius_chip` | 8dp | 类型标签、键帽 |
| `radius_control` | 12dp | 按钮、输入框、图标按钮、缩略图 |
| `radius_card` | 16dp | 作品卡、剪贴板横幅、设置分组 |
| `radius_sheet` | 24dp | 底部面板、对话框 |
| `radius_pill` | 999dp | 搜索框、分段控件、筛选胶囊 |

## 边框、阴影、高度

- 卡片、图标按钮、次要按钮**休息态不描边**。层次靠 `canvas_bg` 上的 `canvas_surface`，以及 `canvas_surface_subtle` 的色块。
- 描边只留给：输入框获得焦点、搜索框获得焦点。选中行用选中底色，不再加一圈粗描边。
- 不用投影做层级。底部面板和对话框靠更深的遮罩（`canvas_scrim`）和抬高的表面色。

## 字体

| 角色 | 字号 |
| --- | --- |
| 页面标题 | 20–22sp，粗体 |
| 列表标题 | 15sp，粗体 |
| 正文、按钮 | 14–15sp |
| 说明 | 13sp，行距 1.4 |
| 元信息 | 12sp |

1.3 倍系统字号下，行高必须跟着文字变，不能写死把第二行裁掉。

## 颜色

浅色页面底 `#F5F7FA`，卡片白。深色页面底 `#0D1420`，卡片 `#151E2C`。
强调色只有靛蓝。危险动作用淡红底加红字。深色不是浅色取反，每个文字色单独写过。

## 触控

可点目标至少 `touch_min`（48dp）。筛选胶囊、顶栏图标、列表上的「更多」都按这个来。

## 动效

180–220ms。进入用减速，离开用加速。内容没变就不做动画。

## 横屏

横屏高度紧。预览收起「刷新 / 联网 / 全屏」和脚本开关，只留标题、代码/预览切换和缩放。
首页横屏去掉副标题，主按钮变矮，把高度留给列表。
