# 设计系统 · Atelier（v0.3.0）

> 代码画布是一个**作品的画廊**，不是文件管理器。
> 这句话决定了后面每一条规则：内容（渲染出来的图）是主角，界面只是它的墙和灯。

本文件是 v0.3.0 起的唯一设计依据。颜色、形状、图标、动作面板、弹窗的唯一来源都在这里；
`ColorContrastTest` / `ThemeContrastInstrumentedTest` / `DesignSystemRegressionTest` 是它的可执行版本。

---

## 1. 定调

| 维度 | 决定 | 理由 |
|---|---|---|
| 气质 | 画廊 / 排版感，克制的纸面 | 用户的核心动作是"看作品"，界面不该抢 |
| 强调色 | 单一靛蓝 `primary` | v0.2.x 一屏里蓝/薄荷绿/紫各自抢焦点；现在只有一处强调 |
| 表面 | 四层：`bg` → `surface` → `surface_elevated` → `code_surface` | 抽屉/面板/弹窗需要"比卡片再高一档"的层级 |
| 圆角 | 8 / 12 / 16 / 20 / 24 / 999 六档，不再出现其它数值 | 圆角混乱是"像是随手做的"最大来源 |
| 阴影 | 几乎不用；用描边 + 一档底色抬升代替 | 深色下重阴影必糊，浅色下轻阴影更干净 |
| 动效 | 180–220ms，Decelerate 进 / Accelerate 出 | 比系统默认更快，不拖沓 |
| 图标 | 24 网格 / **1.8dp 描边**（全套一个数值）/ 圆头圆接 | 一套语言，任何一个不能是例外 |

### 1.1 借鉴与有意偏离

设计方向对照了 2025–2026 的主流做法（Material 3 Expressive 的五个杠杆：更鲜明的色彩角色、弹簧动效、
对比形状、可变排版、自适应组件；以及 Linear / Raycast / Notion 这一档产品的"极简即奢侈"路线）。
取了一半：

| 主流做法 | 本应用 | 原因 |
|---|---|---|
| M3 Expressive：多色、鲜活的配色角色 | **只保留一个强调色** | 画廊的框不该和画抢 |
| M3 弹窗顶角 28dp、句柄 32×4dp、遮罩 32% | 24dp / 36×4dp / 遮罩 50% | 手机窄屏上 28dp 显得过软；遮罩压到 32% 时下层内容仍在抢注意力 |
| M3：动作面板里危险动作"只用红字，不用红底" | **淡红底 + 红字 + 说明文字** | 面板里六个动作等权时，"删除"必须一眼可辨；淡底比纯红填充温和，比纯字更醒目。这是有意的偏离 |
| M3 抽屉最宽 360dp | 294dp | 单手可及，且不遮住左列的缩略图 |
| Coil 默认交叉淡入 200ms | 180ms | 内存命中时不加任何动画（那才是"闪"的根因） |
| 骨架屏 shimmer 占位 | 类型封面（HTML/SVG/XML 线稿图形） | 封面是**诚实**的占位：它明确表示"缩略图还没生成"，而灰块 shimmer 在画廊里只是噪声 |

## 2. 颜色

### 2.1 语义 token（唯一来源：`res/values/colors.xml` 与 `values-night/colors.xml`）

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `canvas_bg` | `#F5F7FA` | `#0D1420` | 页面底 |
| `canvas_surface` | `#FFFFFF` | `#151E2C` | 卡片 |
| `canvas_surface_subtle` | `#EDF1F7` | `#1E2939` | 搜索槽、缩略图井、chip |
| `canvas_surface_elevated` | `#FFFFFF` | `#202D40` | 抽屉、底部面板、弹窗 |
| `canvas_border` | `#DCE3EC` | `#2E3D52` | 1dp 描边 |
| `canvas_border_strong` | `#74849B` | `#63768F` | 真正的边界（聚焦描边、胶囊轨道） |
| `canvas_ink_primary` | `#1A2433` | `#F2F6FB` | 标题、值 |
| `canvas_ink_secondary` | `#53627A` | `#B4C1D4` | 正文、次要说明 |
| `canvas_ink_tertiary` | `#5F6F86` | `#93A1B5` | 计数、时间戳、占位提示 |
| `canvas_icon_on_surface` / `_subtle` | `#44536B` | `#C8D4E4` | 细线图标 |
| `canvas_primary` | `#2456C6` | `#8EB4FF` | 唯一强调色 |
| `canvas_selection` | `#D9E4F8` | `#24364F` | 多选行底色、剪贴板横幅 |
| `canvas_danger` / `_surface` | `#B42318` / `#FBE4E1` | `#FF9E9E` / `#3A1D1E` | 不可撤销的动作 |

### 2.2 硬性约束（由 `ColorContrastTest` 执行，改色即失败）

- 普通文字 ≥ **4.5:1**：`ink_*` 对 `bg` / `surface` / `surface_subtle` / `surface_elevated`
  全部成立；`ink_tertiary` 在 `bg`/`surface`/`surface_elevated` 上 ≥4.5，只有在
  `surface_subtle`（只用于 chip / 搜索框这类非正文）允许降到 3:1。
- 功能色（图标、描边、选中指示）≥ **3:1**。
- `danger` 对 `danger_surface`、`on_danger` 对 `danger`、`ink_*` 对 `selection` 全部 ≥4.5。
- 深色不是浅色的反转：每个 ink token 的亮度必须高于浅色版（`nightPaletteIsGenuinelyReAuthored…`）。

> **教训（v0.2.0 幽灵齿轮）**：深色顶栏图标曾用 `#3A3F4C` 近黑描边压近黑底，几乎看不见。
> 现在 `icon_on_subtle` 在深色是 `#C8D4E4`，对最亮的浮起面仍有 9.26:1。

## 3. 形状与层级

```
8dp    小：tag、chip、快捷键键帽
12dp   中：按钮、输入框、缩略图
16dp   大：作品卡、剪贴板横幅
20dp   超大：对话框
24dp   面板：底部动作面板（只圆上两角）
999dp  胶囊：搜索框、筛选 pill、分段轨道
```

- **不用阴影做层级**：卡片 = 1dp 描边；抽屉/面板用 `surface_elevated` + `elevation` 一档。
- 分段控件（列表/方格）轨道 = `canvas_segment_track` + 选中胶囊 = `primary` 填充。

## 4. 图标

一套自制矢量图标，规则只有四条：

1. **24×24 网格**，图形主体占 4–20，四周留白一致。
2. **描边 1.7–1.8dp**，`strokeLineCap="round"`、`strokeLineJoin="round"`、`fillColor="#00000000"`。
   仅 `ic_more`、`ic_check`、封面图形是填充式（它们本来就该是实心）。
3. **一个概念一个图形**。导出与分享曾共用"托盘 + 向上箭头"，读起来是同一个动作；
   现在导出 = 带折角的文档 + 落到文档上的箭头，分享 = 托盘 + 向上箭头。
4. **不自造隐喻**。设置曾画成"圆 + 八条射线"，实机上被读成"太阳/亮度"；
   现在是与真实齿轮多边形（8 齿 + 中心轴孔）。

清单（`res/drawable/ic_*.xml`）：settings / add / import / export / back / delete / edit / share /
search / paste / refresh / undo / redo / save / find / network / update / view_list / view_grid /
more / open / copy / check / close / clipboard_in / select_all / menu。

### 4.1 应用图标（启动器）

构成只有三件事，都在自适应图标的安全区内（中心 66dp）：

| 层 | 是什么 | 文件 |
|---|---|---|
| 底 | 墨色画布 `#0D1420` | `drawable/ic_launcher_background.xml`（纯色 shape） |
| 图 | 代码 `< >` + 作品（青绿色块） | `drawable-*/ic_launcher_foreground.png`（5 个密度） |
| 单色 | 同一形状的剪影 | `drawable-*/ic_launcher_monochrome.png` |

**两条来自实机验证的硬约束**，不是审美偏好：

1. **笔画在 108 视口里要 ≥10dp。** 启动器图标最常以 48dp 出现，折算约 4.4px；
   低于这个数值的描边在那个尺寸上直接消失。前几版按 4–6dp 画，装上机器只剩几个点。
2. **不要用浅色铺满整块图标。** 浅底 + 深色标记在合成预览里很好看，
   放到真实桌面（深色壁纸、旁边是一圈彩色图标）读作"这个图标没加载出来"。
   深底 + 一处亮色才读作"一个品牌"。

**图标颜色必须与主题解耦。** 图标资源是按"启动器当前的主题"解析的，而启动器不总是跟着应用的
深浅色走：背景层一开始写的是 `@color/canvas_bg`，在浅色启动器上被解析成 `#F5F7FA`，
白色标记压上去直接消失，整个图标只剩一个绿点。现在这一层硬编码 `#0D1420`。

**标记本身是生成的，不是画的。** 流程：生图（`ai-image-generation` skill）→ 按背景色做软阈值
抠图得到透明前景 → 缩放到 5 个密度。抠图时把主体控制成约 53% 宽，落进 66dp 安全区；
背景交回设计系统的墨色，所以图标底色与界面底色是同一个值。

**已知现象**：在 Android 模拟器的 NexusLauncher 上，这个图标外圈会多出一圈浅蓝
（`#AADAFF`）描边；同一屏幕上其它图标没有。已排除前景 PNG 残留（alpha 边缘 0→255 一步到位）
与 `<monochrome>` 层（移除后仍在）。待真机确认，暂记为模拟器渲染差异。

## 5. 唯一动作面

所有"这件事你想怎么做"的菜单只允许一种形态：**底部动作面板**（`CanvasBottomSheet`）。

- 顶部 36×4dp 拖动手柄（`bg_sheet_handle`），只圆上两角 24dp。
- 标题 17sp 粗体 + 可选的 12sp 副标题（文件名/上下文）。
- 每行 52dp：22dp 前置图标 + 15sp 标签 + 可选 12sp 说明；按下时行内出现 `surface_subtle` 填充。
- **不可撤销的动作单独一行**：`danger_surface` 底 + `danger` 文字 + "无法撤销"说明。
- 遮罩 `dimAmount = 0.5`。

统一的对话框只有两种（都在 `CanvasConfirmDialog` / `UiDialogHelper` 里，不许另起）：

| 形态 | 用途 | 规格 |
|---|---|---|
| 输入框 | 新建/重命名/跳转到行 | 20dp 圆角，`bg_input_field` 输入底，实时校验禁用确认键 |
| 确认框 | 删除、联网授权、预览崩溃重建 | 20dp 圆角，取消（透明胶囊）+ 确认（主色或危险色） |

**反例（v0.2.x）**：`AlertDialog.Builder.setItems()` 的系统列表、"⋮" 上的 `PopupMenu`、
标题+消息+三个系统按钮的删除确认——三套完全不同的房间。现在全部删除。

## 6. 交互

### 6.1 浏览
- 单击卡片 → 预览；长按 → 进入多选（不是弹菜单）。
- 多选：顶部上下文操作条覆盖顶栏（列表不重排），计数 + 全选 + 分享 + 删除；
  选中行 = `selection` 底 + `primary` 1.5dp 描边 + 实心勾徽章。
- 返回键：先退多选 → 再关抽屉 → 才退出应用。

### 6.2 目录抽屉
- 左侧滑出 294dp，遮罩点击/关闭按钮/返回键均可收起，220ms Decelerate。
- 头部"目录 + 数量"，一行类型 pill（全部/HTML/SVG/XML/其它，单选），
  完整作品索引（缩略图 + 名称 + 类型·大小），底部固定"设置"。
- **筛选与搜索共用一个管线**：抽屉的 pill、搜索框、画廊列表读同一份 `filteredDocuments`，
  所以顶部计数、抽屉索引、画廊三处的数字永远一致。

### 6.3 剪贴板自动识别
- 打开应用时若剪贴板内容**确实是可渲染标记**（根元素是 SVG/HTML/XML，或能识别出代码块），
  列表顶部出现一条横幅：图标 + "检测到剪贴板代码" + 内容摘要 + 导入并预览 + 关闭。
- 纯文本/聊天记录不弹（`RenderKindDetector` + `AiCodeExtractor` 双重判定）；
  同一条内容只问一次；可在设置里彻底关掉。
- 导入仍走"粘贴并预览"的完整链路（多段代码 → 动作面板选择）。

### 6.4 缩略图不闪
- v0.2.x：每次绑定都先画类型封面，再异步把位图换上去 —— 每次进入列表都闪一下。
- 现在：绑定时先查进程内 `LruCache`；命中就直接落图，不再中间渲染一次；
  只有真正本次渲染中才生成的缩略图才从类型封面渐变进入。

## 7. 排版

| 角色 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 页面标题（代码画布 / 目录 / 设置） | 21sp / 21sp / 18sp | bold | ink_primary |
| 区块标签（我的文件 · N） | 13sp，letterSpacing 0.02 | bold | ink_tertiary |
| 列表标题 / 卡片标题 | 15sp / 13sp | bold | ink_primary |
| 正文说明 | 13–14sp，行距 ×1.4 | regular | ink_secondary |
| 元信息（大小 · 行数、时间戳） | 11–12sp | regular | ink_tertiary |
| 面板标题 / 行标签 | 17sp / 15sp | bold / regular | ink_primary |

- 数字与拉丁字形走系统字体，中文走系统中文字体；中英混排不额外加空格。
- 一屏内的字重不超过三档。

## 8. 没有做的事（有意）

- **不引入 androidx / Material 组件库**：整包 1.1MB 级是这个应用的资产，
  抽屉、面板、对话框都是自绘的，代价可控、收益是体积。
- **不做滑动删除**：行有两个动作入口（⋮ 面板 + 长按多选），再加手势会互相打架。
- **不给"圆角可调"这类外观选项**：一个应用只该有一套写法。
