# 代码画布 v0.1.3 · 界面重做

这一版不加功能，只修一件事：**上一版的界面根本没达到能交付的样子**。

## 为什么会有这一版

v0.1.2 的"验收通过"只验了三件事——对比度数值达标、测试全绿、不崩溃。那是**无障碍与功能**验收，我把它当成了**画面好不好看**的验收。拿模拟器真实画面逐屏看下来，问题一大把：白底工具栏直接硬切到近黑画布、内置示例内容挤在顶部而下面 70% 是死空、每个图标被一圈灰方框包着、一屏里蓝色/薄荷绿/紫色各自抢焦点、蓝色版本号常驻主页底部。这些测试一条都测不到。

所以这一版按「干净细线条」重做，并把**每个屏幕的真实截图**作为验收证据。

## 改了什么

**内置示例页（客户第一次打开看到的东西）**
- 原来是深色近黑底 + 青绿标签/按钮，内容全部挤在顶部 30%，下面一大片空。现在是垂直居中的极简页，浅色/深色各自适配，只用**一个强调色**（品牌蓝）。
- 文案缩短到一行，去掉了"果。"这种孤字折行。
- 示例页里直接写明"脚本开关关闭时，这个按钮不会响应"——之前开关是关的、按钮却照样高亮，自相矛盾。

**预览画布**
- 由"顶到屏幕边缘的深色块"改成**落在浅色底上的圆角卡片**（1dp 细边 + 16dp 圆角 + `clipToOutline`），彻底消除白 chrome 与画布的生硬硬切。
- 画布底色改为跟随主题（浅色模式白、夜间深色），夜间下示例文字清晰、无浅色残留。

**统一的"细线条"语言**
- 顶栏、编辑器工具栏、卡片上的**图标全部去掉灰色描边框**，改成无框细线图标 + 按下态浅色底。
- 分段控件（代码/预览）选中态原来是 `setBackgroundResource(R.color.…)`——**画笔的是一个方角纯色块**，压在圆角轨道上必然会溢出。现在改为 999 圆角胶囊。
- 主页视图切换由"薄荷绿方框"（`bg_tag`，语义是"成功/标签"色）改为浅色轨道里的蓝色胶囊，图标随选中态自动换白。

**主页**
- 搜索框补上放大镜图标，去掉生硬描边（只在获得焦点时才出现描边，作为真实的焦点指示）。
- 文件类型标签去掉紫色，改中性小胶囊；卡片内部从三行人肉堆叠压成两行，信息密度更合理。
- 底部版本号从**蓝色大字常驻**改为安静的中性灰小字，只有真的发现新版本时才变成主色。
- 文件类型封面图标重画为单色线性图形（浏览器窗口 / 贝塞尔曲线 / 尖括号）——原来三个都是紫色，而且其中一个几乎看不见。
- 缩略图加了一层 **foreground 描边**：渲染出的缩略图若是白底页面，会把背景边框整个盖掉，看起来像"图标丢了"。

**编辑器**
- 符号快捷键栏移到底部（键盘弹出时正好在键盘上方），不再白占顶部一行；并加了横向渐隐提示，暗示右侧还有内容。
- 撤销/重做/粘贴统一为无框样式（"粘贴"是纯文字按钮），"已自动保存"由鲜绿色改为中性灰。

## 验证

- JVM 单元测试 **47 项 0 失败**（含两套主题的 WCAG 对比度交叉校验）。
- 模拟器仪器测试 **20 项 `OK (20 tests)`**，覆盖真机渲染对比度、列表/方格密度与跨重启记忆、切换不重载、查找替换可撤销、XML 结构视图不等待 WebView。
- 逐屏截图（浅色 + 夜间）见 [docs/evidence/v0.1.3](evidence/v0.1.3/)，并已用视觉复核：无生硬硬切、无死空、无方框图标、无紫色残留、无浅色模式泄漏。

## 尚未做 / 明确不做

- **仍未在小米 Turbo 3 真机验证**（模拟器已全绿）。输入法、手势导航、120Hz 动画、厂商后台限制下的更新安装都需要你实机确认。
- **代码编辑器还没有行号栏（gutter）**。这是真实缺口，但属于独立的较大改动，没有塞进这一版滥竽充数。要的话下一版单独做。
- 卡片仍用 1dp 细边而非投影——刻意保持平静，不做悬浮阴影。
