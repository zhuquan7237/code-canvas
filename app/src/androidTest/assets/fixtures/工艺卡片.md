# 激光焊接工艺卡片

异种不锈钢激光焊接的**参数窗口**与验收要点，用于现场核对。

## 参数表

| 参数 | 符号 | 取值 | 说明 |
| --- | --- | --- | --- |
| 激光功率 | *P* | 2.4 kW | 光纤激光，连续模式 |
| 焊接速度 | *v* | 3.2 m/min | 保护气侧吹 |
| 离焦量 | *f* | −1.5 mm | 负离焦增加熔深 |
| 保护气流量 | *Q* | 18 L/min | 氩气 |

## 熔深估算

熔深与线能量的关系可以近似写成：

$$E = \frac{P}{v}, \qquad h \approx k\sqrt{E}$$

其中 $E$ 为线能量（J/mm），$k$ 为材料系数，本次试验取 $k = 0.42$。

## 代码片段

```python
def line_energy(power_kw: float, speed_m_per_min: float) -> float:
    """线能量 J/mm。"""
    return power_kw * 1000.0 / (speed_m_per_min * 1000.0 / 60.0)
```

> 注意：负离焦时保护气必须侧吹，否则等离子体会屏蔽入射光。
